# DEV-SPRI-001

## TP2 – Console d’administration de salles de réunion

En vous inspirant de ce que vous avez fait dans le TP1, vous devez développer une application en mode console qui permet à un administrateur de gérer la réservation de salles de réunions dans son entreprise.

Une salle de réunion possède :

- Un ID
- Un nom
- Une capacité

Une réservation comporte :

- Une salle
- Une date
- Un horaire de début
- Un horaire de fin

Les salles peuvent être réservées dès 8h et doivent être libérées à 18h au plus tard.
Afin de gérer au mieux ses salles, l’admin souhaite pouvoir créer, supprimer ou modifier des salles à volonté. Créer et supprimer des réservations.
Etre prévenu en cas de conflit d’horaire (impossible de valider une réunion dans une salle déjà prise)

Afficher les réservations :

- Par salle
- Par date
- Par capacité minimale

Afficher les salles disponibles par créneau (heure de début et heure de fin)
